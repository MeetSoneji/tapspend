# Code of Conduct

Be kind and respectful. We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/): no harassment, discrimination or personal attacks; assume good faith; give and accept constructive feedback gracefully.

Report problems to the maintainers privately via the repository's security-advisory contact. Maintainers may remove comments or contributions that break these rules.
